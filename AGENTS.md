# Indicaciones para el proyecto

- Mantener el repositorio limpio y coherente tras cambios de dirección o actualizaciones importantes: retirar artefactos generados y documentación obsoleta creada por el trabajo, sin borrar cambios ni datos del usuario.
- El motor está en fase experimental: usar datos sintéticos y carpetas desechables. No operar sobre respaldos personales ni el destino de FreeFileSync.
- No presentar pruebas parciales como garantías de recuperación o durabilidad. Actualizar README y PLAN cuando cambie el alcance o estado real.
- Antes de publicar, revisar que no haya rutas personales, secretos, datos privados ni artefactos de compilación.
